#  House Price Prediction using Linear Regression & Polynomial Regression

## Project Overview
This project predicts house prices based on *area (square feet)* and *number of rooms* using *Linear Regression*, which is a supervised machine learning algorithm.

The project is designed to understand:
- Data preprocessing
- Linear Regression working
- Model training and evaluation

---

## Algorithm Used
*Linear Regression*

Linear Regression is used because house price generally increases linearly with:
- Area of the house
- Number of rooms

*Polynomial Regression*

polynomial Regression is an extention of Linear Regression that models non-linear relationships by adding polynomial terms.
It helps the model fit complex patterns in the data.

---

*File Name:* `House Price Prediction Dataset.csv'
 Real world dataset from kaggle.com

---

## Technologies & Libraries Used
- Python
- Pandas
- Scikit-learn

## Data Preprocessing Steps
1. Loaded the dataset using pandas
2. Checked missing values and duplicates
3. Selected input features and target variable
4. Applied feature scaling using StandardScaler
5. Split the dataset into training and testing data

---

##  Model Training
- The dataset is split into *80% training* and *20% testing*
- Linear Regression model is trained using training data
- Predictions are made on test data

---

##  Model Evaluation Metrics
- *Mean Squared Error (MSE)*
- *R² Score*

These metrics help evaluate the accuracy and performance of the model.

---

##  Project Workflow
1. Import required libraries
2. Load dataset
3. Perform data preprocessing
4. Train model 
5. Predict house prices
6. Evaluate model performance

The Linear Regression & Polynomial Regression model successfully predicts house prices based on area and number of rooms.
